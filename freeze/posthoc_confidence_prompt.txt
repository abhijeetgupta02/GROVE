Inspect this construction site image for visible safety violations.
Judge only visible physical conditions. Safety equipment (guardrails, harnesses, hard hats, vests, barriers) and normal tools in safe use are NOT violations.
Image size: {W} x {H} pixels.

Answer for each category:
Fall_Hazard: Is a worker exposed to falling into an unguarded trench/opening or from an elevated edge, roof, ladder, or scaffold that lacks guardrails or a tied-off harness?
Electrocution_Hazard: Is there an unprotected electrical hazard, such as damaged or exposed live wiring, makeshift power hookups, or work dangerously close to overhead power lines?
PPE_Violation: Is a visible construction worker missing a required hard hat, high-visibility vest, eye protection, or task-specific protective gear (excluding fall harnesses)?

For each category give:
present: true only if the violation is clearly visible, otherwise false.
evidence: one short clause describing what you see.
bbox: [x1, y1, x2, y2] integer pixel coordinates of the violation, or [] if absent.
confidence: how sure you are that this violation is present, 0 to 100.

Return JSON only.
